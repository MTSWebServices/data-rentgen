# 0.7.0 (2026-07-29) { #0.7.0 }

## Breaking Changes

Moved `server.session` middleware settings to `auth` block. Also renamed some fields in `auth.keycloak` settings block. ([#508](https://github.com/MTSWebServices/data-rentgen/issues/508))

Before:

```yaml
auth:
  provider: ...
  keycloak:
    server_url: ...
    redirect_url: ...

server:
  session:
    enabled: true
    secret_key: ...
```

Now:

```yaml
auth:
  provider:
  keycloak:
    api_url: ...
    ui_callback_url: ...
  cookie:
    secret_key: ...
```

## Improvements

- Speed by server & http2kafka components by dropping FastAPI `dependency_overrides` feature. ([#511](https://github.com/MTSWebServices/data-rentgen/issues/511))

    See [fastapi #14441](https://github.com/fastapi/fastapi/pull/14441).

- Cache Keycloak certs for JWT token validation. ([#512](https://github.com/MTSWebServices/data-rentgen/issues/512))

    Previously every API request with KeycloakAuthProvider enabled made a request to Keycloak.
