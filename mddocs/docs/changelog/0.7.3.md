# 0.7.3 (2026-10-28) { #0.7.3 }

## Bug Fixes

- Now `create_partitions` script uses `y2025_m10_d25` format instead of `y2025_m10_25` for partitions with daily granularity. ([#541](https://github.com/MTSWebServices/data-rentgen/issues/541))

- Fixed `cleanup_partitions` selecting a partition by its start date, so it truncated, detached or dropped partitions that still held rows newer than `--keep-after`. Daily partitions created by `create_partitions` are now recognized as well. ([#541](https://github.com/MTSWebServices/data-rentgen/issues/541))
