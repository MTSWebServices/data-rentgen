Moved `server.session` middleware settings to `auth` block. Also renamed some fields in `auth.keycloak` settings block.

Before:

```yaml
auth:
  provider: ...
  keycloak:
    server_url: ...
    redirect_url: ...

server:
  session:
    enabled: true
    secret_key: ...
```

Now:

```yaml
auth:
  provider:
  keycloak:
    api_url: ...
    ui_callback_url: ...
  cookie:
    secret_key: ...
```
